# Tela Inteligente

Protótipo web do app Tela Inteligente para testes com alunos e responsáveis.

## Como testar localmente

Abra o arquivo `index.html` no navegador.

## Como publicar para outras pessoas testarem

Este projeto é estático. Pode ser publicado em:

- GitHub Pages
- Netlify
- Vercel

Arquivos necessários:

- `index.html`
- `styles.css`
- `app.js`
- pasta `data/`

## Senha do responsável

Senha padrão do protótipo:

`1234`

## Observação

No navegador, as configurações ficam salvas em `localStorage`. Cada pessoa que testar terá seu próprio armazenamento local.
